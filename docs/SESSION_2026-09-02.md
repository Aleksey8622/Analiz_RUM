  Excel files.
- BOM search returns complete level-zero blocks in source row order.

  deletions. Source Excel remains unchanged.

  commas, semicolons, or line breaks.

  selected rows and are persisted through the SQLite directory mechanism.

  item name.
- Expand/collapse controls show arrow icons without visible action words.
- The current source version was published through the existing workbook-based
  synchronizer and was received successfully on the second managed device.

## Delivery boundary

The workbook synchronizer is the source of the exact managed-device project
state. This Git repository stores source history and continuation context but
must not contain operational SQLite databases, reports, local configuration,
network paths, or synchronization workbooks.

Before continuing on another device, receive the latest workbook update, build,
launch, and verify the real application. Do not overwrite a newer managed-device
copy with an older Git checkout.
