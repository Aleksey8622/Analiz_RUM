# Ручной перенос Analysis Room

## Целевая папка

Проект создаётся на рабочем столе в папке `Analysis Room` и открывается в VS Code
целиком. Точный абсолютный путь зависит от имени пользователя Windows и нигде в
исходном коде не хранится.

## Что переносится текстом

- корневые файлы конфигурации проекта;
- `src/`;
- `electron/`;
- `database/schema/`;
- необходимые файлы `docs/` и пустые служебные каталоги.

## Что не переносится

- `node_modules/` и `dist/`;
- `analiz-rum.config.json`;
- `data/` и `analiz_rum.db`;
- Excel-файлы, выгрузки, логи и временные файлы;
- `.git/` и настройки удалённого репозитория.

## Локальная конфигурация

На рабочем компьютере создаётся `analiz-rum.config.json` по примеру
`analiz-rum.config.example.json`. В нём указывается папка рабочих Excel-файлов.
SQLite рекомендуется хранить в `./data`, то есть внутри локальной папки проекта.

## Контрольные точки

1. После корневых файлов: `npm install`.
2. После React-каркаса: `npm run build`.
3. После всех исходников: `npm run build`.
4. После Electron и SQL: `npm run desktop:dev`.
5. После локальной конфигурации: импорт обезличенного тестового справочника.
6. Только после успешного теста: подключение рабочих Excel-файлов на VDI.

## Справочник позиций

Распознаются файлы Excel, в названии которых присутствует «Справочник позиций»,
«Справочник», «Карточки позиций» или `directory`. Обязательные столбцы: `PLU`,
`Наименование` и `Поставщик`. `GUID` и `Категория` необязательны. Если категория
не заполнена, приложение определяет её по наименованию; если правило не найдено,
используется категория «Прочее».
