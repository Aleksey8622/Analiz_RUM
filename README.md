# Analiz_RUM

Проект DELEKTO для анализа запасов, заказов, упаковки и этикетки.

## Текущий этап

Подготовлен frontend-каркас и сверстана первая страница авторизации.

## Текущий стек этапа 1

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Следующие подключения

- Electron
- SQLite
- xlsx
- Табличный модуль и бизнес-логика

## Структура

- `src/` - интерфейс приложения
- `electron/` - desktop-оболочка следующего этапа
- `database/` - схема SQLite и миграции следующего этапа
- `storage/` - импорты и экспорты
- `docs/` - проектная документация
