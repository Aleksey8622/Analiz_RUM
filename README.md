# Analiz_RUM

Проект DELEKTO для анализа запасов, заказов, упаковки и этикетки.

## Текущий этап

Подготовлен стартовый каркас проекта без верстки экранов.

## Целевой стек

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Table
- Electron
- SQLite
- xlsx

## Структура

- `src/` - интерфейс приложения
- `electron/` - desktop-оболочка
- `database/` - схема SQLite и миграции
- `storage/` - импорты и экспорты
- `docs/` - проектная документация
